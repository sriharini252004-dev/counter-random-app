I am excited to share my latest React project — React Counter & Random Number Generator.

This project was built to strengthen my understanding of core React concepts and interactive user interface development.

Key Features:
• Increment, Decrement, and Reset functionality
• Counter value restricted from going below zero
• Minimum limit notification using conditional rendering
• Random number generation between 1 and 100
• Dynamic UI updates based on state changes
• Counter and random number history tracking
• Responsive and user-friendly interface

Technologies Used:
React JS | JavaScript | CSS3 | Vite

Key Concepts Applied:
useState | State Management | Event Handling | Conditional Rendering | Dynamic Rendering

Through this project, I gained hands-on experience in managing component state and building interactive applications using React.
